# Admin Guide

Use `/admin` to manage normal website content.

Common updates:

- Change homepage headline: edit Homepage settings
- Change logos: edit Global Site Settings
- Add a program: create a Program entry
- Add an event: create an Event entry
- Add an article: create an Article entry
- Change external URLs: edit Global Site Settings or the relevant content entry

Each saved change becomes a Git commit and can be rolled back through repository history.
